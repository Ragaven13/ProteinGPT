# ProteinGPT: Generative Transformer for Functional Protein Sequence Design

ProteinGPT is a transformer-based research project for protein sequence generation, function prediction, and conditional functional protein design using UniProt Swiss-Prot protein sequences.

## Goals

- Generate realistic protein sequences
- Predict protein function from sequence
- Generate proteins conditioned on desired function labels
- Evaluate biological similarity and sequence quality

## Dataset

- UniProt Swiss-Prot FASTA
- Stored locally in `data/raw/`
- Not included in GitHub repository
